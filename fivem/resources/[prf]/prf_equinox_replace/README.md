# Chevrolet Equinox 2020 PRF — FiveM Legacy

Autores do veículo: **Martinelli e Alessandro da Fonseca**. Integração técnica: **Nova Byte**.

**Autorização:** o solicitante informou ter autorização dos autores para republicar o veículo neste projeto. A Nova Byte não reivindica autoria dos arquivos 3D ou texturas; mantenha os créditos e guarde o comprovante da autorização.

O recurso substitui o veículo nativo GTA V `police` em todo o servidor, não é um carro `addon` independente. O manifesto é mantido aqui; os quatro arquivos de modelo e textura são: `police.yft`, `police_hi.yft`, `police.ytd`, `police+hi.ytd` em `stream/`.

Importação automatizada opcional em `.github/workflows/import-equinox-prf.yml`, verificando o hash do RAR original e de cada modelo antes de publicar. Se a hospedagem bloquear a importação, use o recurso pronto fornecido pelo proprietário e faça upload manual dos quatro arquivos em `stream/`. Nunca suba a chave do servidor Cfx.

Fonte original: https://www.gta5-mods.com/vehicles/equinox-2020-prf-blindada
